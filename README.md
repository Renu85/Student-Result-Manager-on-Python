# Personal Password Manager
Developed a Personal Password Manager using Python that helps users securely store and manage passwords for different websites. The application allows users to save passwords, view stored credentials, and generate strong random passwords using a combination of letters, numbers, and special characters. Password data is stored in a text file, enabling access to saved information even after restarting the program. This project demonstrates Python concepts such as file handling, dictionaries, loops, functions, exception handling, and user input management.
